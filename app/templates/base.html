About BookNest

BookNest is a lightweight, cloud-native online bookstore built with Flask.

  • Architecture: Python 3.12, Flask, Gunicorn WSGI.
  • Frontend: Clean HTML5, CSS3, and vanilla JavaScript without heavy frameworks.
  • Demo Payments: Checkout is simulated only. No card details are collected and no real money is charged.
  • Cloud Ready: Native health check endpoint (/health) for Kubernetes probes, Docker containerized, and GitOps ready.
